# Getting Started

This section covers the minimum setup to get productive with REVO Bridge.

Recommended order:

1. Introduction
2. Installation and Update
3. First Try

## What you will set up

- Install the Blender extension from `REVO_Bridge_Blender.zip`
- Point REVO Bridge at each DCC executable
- Install the ZBrush, Maya, Toolbag and Painter plugins from **Integrations**
- Restart those applications and confirm a first send/receive

Continue to [Introduction](introduction.md).
